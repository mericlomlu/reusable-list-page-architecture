# Clean-room and confidentiality

- Private ListLayout materials are behavioral reference only.
- Never copy source lines, file structure, component APIs, comments, type names, query constants, service contracts, UI assets, or documentation text from the private implementation.
- Never import or recreate `@vtouch` packages, client identifiers, customer/session concepts, insurance terminology, or private API models.
- Reframe requirements in generic language before implementation.
- Use original names, original typed contracts, shadcn primitives, and fictional Developer Workspace data.
- If a decision appears specific to the private implementation rather than the general problem, stop and ask before using it.
