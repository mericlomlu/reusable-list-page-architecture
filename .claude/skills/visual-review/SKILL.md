# Visual review

1. Read the design-handoff reference and inspect only the relevant artboards and states.
2. Compare desktop, tablet, and mobile implementations in light and dark themes.
3. Check layout, hierarchy, typography, tokens, spacing, long-record rhythm, toolbar density, sidebar behavior, states, and motion.
4. Distinguish implementation defects from intentional responsive recomposition.
5. Return prioritized discrepancies with expected design behavior and likely file locations.

Do not use this skill before an approved handoff exists. Do not edit code unless asked.
