# Responsive review

Inspect at 1440, 1280, 834/768, and 390/375 widths.

- Desktop: persistent sidebar, scannable long records, coherent toolbar.
- Tablet: compact navigation, controlled toolbar wrapping, progressive metadata reduction.
- Mobile: navigation and filters in accessible drawers, stacked records, reachable bulk actions, no horizontal overflow.
- All widths: stable loading layouts, readable empty/error states, usable pagination, 44px targets, light/dark parity.

Report viewport, impact, expected behavior, and file location. Do not edit code unless asked.
