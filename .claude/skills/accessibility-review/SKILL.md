# Accessibility review

Report PASS, FAIL, or N/A for:

1. landmarks and heading hierarchy;
2. labels, descriptions, and accessible names;
3. keyboard order, focus visibility, and focus restoration;
4. filter draft/apply/reset behavior;
5. selection, select-all, counts, and bulk actions;
6. loading, result changes, empty, and error announcements;
7. non-color status meaning and WCAG AA contrast;
8. mobile drawer semantics and background isolation;
9. reduced motion and touch targets.

Include file and line for failures and a concrete fix. Do not edit code unless asked.
